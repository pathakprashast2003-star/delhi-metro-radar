# Delhi Metro Radar 🚇

A live, real-time Delhi Metro train tracker built with open-source data.

> **Unofficial project** — Not affiliated with DMRC or Government of NCT of Delhi.

## Tech Stack
- MapLibre GL JS (map rendering)
- Turf.js (track interpolation)  
- OpenStreetMap (track data)
- Vanilla JS (no framework needed)

- [ ] Yellow Line
- [ ] Blue Line

## Data Sources
- Station timetables: [OTD Delhi](https://otd.delhi.gov.in)
- Track geometry: OpenStreetMap contributors

## Legal
Map data © OpenStreetMap contributors (ODbL).
This is an independent visualization project. Train positions are schedule-based simulations.

## Run Locally
Open `index.html` in your browser — no build step needed.
